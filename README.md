# python-mastery
A comprehensive collection of Python programming concepts, hands-on examples, coding challenges, and real-world projects, from beginner to advanced levels.

1. Clone the repository

git clone https://github.com/siva-ai-labs/python-mastery.git 
cd python-mastery/01-python-basics

Replace the repository URL if your actual repository has a different name.

2. Verify Python installation

python3 --version

3. Run a program

python3 01_employee_salary.py
